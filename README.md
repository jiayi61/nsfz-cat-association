# 卧附藏喵 · 南师附中猫协

南师附中猫协静态网站，包含校园猫档案、救助与照护记录、历次义卖、校园遇猫指南和猫墙联系方式。

网站地址：https://jiayi61.github.io/nsfz-cat-association/

## 文件结构

```text
index.html                 网站页面、样式与交互
assets/
  brand/                   猫协徽标
  cats/                    校园猫档案照片
  illustrations/           首页与指南插画
  join/                    猫墙二维码
  timeline/                救助时间线图片
```

网站为纯静态页面，可直接打开 `index.html` 预览，由 GitHub Pages 发布。
